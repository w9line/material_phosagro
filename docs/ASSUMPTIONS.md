# Допущения

- Для демонстрации используются условные пороги B: 30/25% и C: 35/25%; это не нормативы ФосАгро.
- Для GOOD/REWORK/REJECTED применены коэффициенты 1.0/0.9/0.0 из ТЗ.
- Хранилище по умолчанию — SQLite для локального запуска; PostgreSQL не добавлялся, чтобы не усложнять первый локальный запуск.
- Веб-интерфейс — лёгкий статический клиент без сборки React; API и бизнес-логика остаются независимыми.
- LLM отключён без `LLM_API_KEY`; основные операции работают офлайн.
